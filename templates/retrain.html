Pipeline CRISP-DM Otomatis:
  1. Data Cleaning: Duplikasi, inkonsistensi data, missing value (median imputation), outlier capping (IQR)
  2. Feature Engineering: Fitur turunan + ordinal & one-hot encoding
  3. Class Weight Balanced: Pembobotan otomatis kelas minoritas (churn)

  5. Threshold Optimization: Memaksimalkan F1-Score (bukan default 0.50)
  6. Overfitting Detection: Bandingkan Train vs Test ROC-AUC
